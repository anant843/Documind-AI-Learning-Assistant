# Design system

## Direction
Academic workbench: a focused interface for reading, questioning, and revising study material. It uses the visual language of paper, margin annotations, tabs, and a restrained institutional blue.

## Tokens
- Canvas: #F5F7FA
- Surface: #FFFFFF
- Ink: #18202B
- Muted ink: #667085
- Rule: #DFE3E8
- Annotation blue: #2563EB
- Highlighter: #F4C95D
- Danger: #C2413B
- Radius: 8px controls, 12px surfaces
- Typeface: Manrope Variable

## Components
Use shadcn composition conventions: small primitives, CVA variants, Radix Slot for asChild, visible focus rings, semantic states, and one border or one shadow per surface.

## Layout
The sidebar is compact and stable. Content uses a maximum readable width with a faint document margin rule. Data is shown in rows and grouped surfaces instead of repeated icon cards.

## Rules
No decorative gradients, glow shadows, glass panels, sparkle icons, emoji controls, uppercase tracking as decoration, or identical card grids used as page structure.
